本政策說明海閱筆記的主要資料處理情境。開發者發佈前應依正式版本、SDK、網路行為及 App Store Connect 申報再次確認。

使用者匯入內容

PDF、EPUB、標註、筆記與閱讀記錄用於提供閱讀和管理功能，通常儲存在裝置可用的本機儲存空間。若啟用 iCloud 或裝置備份，Apple 可能處理備份資料。

購買及交易

App 內購買由 Apple StoreKit / App Store 處理。App 可能查詢購買狀態或驗證結果以啟用付費匯出；開發者不應取得完整信用卡資訊。

匯出與分享

當你主動匯出 Word/PDF 或使用 iOS 分享功能時，內容會傳送至你選擇的服務或 App。

網路和第三方服務

Apple 的購買服務可能需要網路。如正式版使用當機監控、分析、外部詞典或 AI 服務，應在發佈前核實與披露；此段不代表這些服務已啟用。

資料控制

可於 App 中管理記錄，並透過刪除 App 或相關文件清理裝置內的資料；備份及第三方資料須另行處理。

兒童與安全

請勿在公開的問題回報中提交含個資的文件、筆記或付款資訊。

政策更新與聯絡

本政策可能隨功能更新調整。可透過下方 GitHub Issues 提出隱私問題；正式發佈前建議提供客服電子郵件。

問題回報與聯絡

請於 GitHub Issues 回報不含敏感資訊的問題。請勿公開私人文件、購買憑證或個資；正式發佈前建議增加客服電子郵件。
