海閱筆記

海閱筆記是一款適用於 iPhone 的 PDF / EPUB 閱讀與讀書記錄工具。你可以匯入自己的電子書、閱讀、標註、管理閱讀記錄，並使用支援的功能匯出閱讀空間內容。

  • 匯入與閱讀本機 PDF / EPUB 文件
  • 對文件進行標註並整理閱讀記錄
  • 透過「我的閱讀空間」集中瀏覽記錄
  • 透過 App 內購買解鎖 Word / PDF 匯出（依 App 內顯示為準）

FAQ

如何匯入書籍？

在 App 中使用匯入入口，從系統「檔案」選取 PDF 或 EPUB 文件。

為什麼部分 PDF 無法選取文字？

掃描版 PDF 可能只有圖片、沒有文字層，因此無法直接選取文字。

如何管理筆記與標註？

在閱讀畫面使用標註工具，並於「我的閱讀空間」檢視記錄；可用操作因檔案類型及版本而異。

購買後仍無法匯出？

請檢查網路及 Apple ID 購買狀態，並使用「恢復購買」（如 App 內提供）。仍有問題請回報裝置、iOS 版本及重現步驟，請勿公開付款資訊。

如何申請退款？

App 內購買由 Apple 處理。可至 reportaproblem.apple.com 提出退款申請。

資料會自動上傳嗎？

請參閱隱私權政策。使用系統分享、備份或其他服務時，也可能受該服務的規則影響。

問題回報與聯絡

如果你在使用海閱筆記時遇到問題，或有功能建議，歡迎透過電子郵件與我們聯絡。

聯絡信箱：seareader.help@outlook.com

為協助我們瞭解並排查問題，請在郵件中提供以下資訊：

  • 裝置型號、iOS 版本及海閱筆記版本
  • 問題描述、發生步驟及相關提示訊息

請勿寄送密碼、完整付款資訊或未經去識別處理的私人文件。

你也可以透過 GitHub Issues 提交不含個人資訊的公開問題或建議。請注意，提交的內容將公開顯示。
