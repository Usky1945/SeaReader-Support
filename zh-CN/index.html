海阅笔记

海阅笔记是一款面向 iPhone 的 PDF / EPUB 阅读与读书记录工具。你可以导入自己的电子书，阅读、标注、管理阅读记录，并在支持的功能中导出阅读空间内容。

  • 导入和阅读本地 PDF / EPUB 文档
  • 对文档进行标注，整理阅读记录
  • 通过“我的阅读空间”集中浏览记录
  • 通过应用内购买解锁阅读空间的 Word / PDF 导出功能（以应用内展示为准）

FAQ

如何导入书籍？

在应用中使用导入文件入口，并从系统“文件”中选择 PDF 或 EPUB 文档。请确保文件未损坏且允许打开。

为什么某些 PDF 无法选中文字？

扫描型 PDF 页面可能只有图片而没有文本层，因此无法像文字型 PDF 一样选择文字。

如何管理笔记和批注？

在阅读界面使用相应的标注工具；在“我的阅读空间”查看记录。具体可用操作取决于文档类型和当前版本。

购买后仍无法导出怎么办？

先检查网络连接及 Apple ID 购买状态，再在应用中使用“恢复购买”（如该入口可用）。若仍失败，请通过下方支持渠道说明设备型号、iOS 版本及问题发生步骤；不要提交密码或付款卡号。

如何退款？

应用内购买由 Apple 处理。退款可前往 reportaproblem.apple.com 按 Apple 的流程提出申请。

文件是否会自动上传？

阅读文件和记录的处理方式请参阅隐私政策。若使用系统分享、备份或外部服务，数据处理也可能受所选服务的规则影响。

问题反馈与联系

请在公开的 GitHub Issues 中提交非敏感问题。涉及私人书籍内容、购买凭据或个人数据时请勿公开上传。发布前建议补充独立客服邮箱。
