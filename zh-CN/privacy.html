首页技术支持隐私政策
简体中文繁體中文English

本隐私政策介绍海阅笔记的主要数据处理场景。发布前，开发者应依据最终上架版本、所集成 SDK、网络行为和 App Store Connect 隐私申报核实本文。

用户导入的内容

用户选择导入的 PDF、EPUB、标注、笔记及阅读记录用于提供本地阅读与记录功能。通常保存在应用可访问的设备存储中；如果启用了 iCloud 或设备备份，相关内容可能由 Apple 的备份机制处理。

购买与交易

应用内购买通过 Apple 的 StoreKit / App Store 处理。应用可能读取购买状态或交易验证结果以决定能否使用付费导出功能。开发者不应收到完整支付卡信息。

导出与分享

当你主动导出 Word/PDF 或通过 iOS 分享菜单分享文件时，导出数据会发送到你选择的目标位置或第三方应用。

网络和第三方服务

Apple 的购买服务可能需要网络。实际发行版本如使用崩溃监控、分析、外部词典或 AI 服务，应在发布前确认其数据流，并在本政策与 App Store Connect 中准确披露；不能仅据此页面推断这些服务已启用。

数据控制

你可以在应用内管理阅读记录，并通过删除应用或相关文档清理设备本地数据；系统备份及已分享至第三方的数据可能需要单独处理。

儿童与安全

请勿在公开问题反馈中上传含个人信息的书籍、笔记或支付凭据。

更新与联系

政策可能因功能更新而修订。对隐私问题可通过下方 GitHub Issues 联系开发者；正式发布前建议提供可直接联系的支持邮箱。

问题反馈与联系

请在公开的 GitHub Issues 中提交非敏感问题。涉及私人书籍内容、购买凭据或个人数据时请勿公开上传。发布前建议补充独立客服邮箱。
